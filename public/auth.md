# Authentication Status

This site is a static, read-only personal website. It does not provide OAuth,
OpenID Connect, token exchange, revocation, agent registration, or authenticated
API access.

Do not send authentication requests or attempt to obtain credentials from this
site. The former endpoint-shaped paths and OAuth/OIDC discovery documents are
not published.

The public profile, project list, and article list are available without
authentication from the homepage, `/index.md`, and the documented read-only
content resources.
